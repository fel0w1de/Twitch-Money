\# Twitch Points Calculator 🎮



Простой и удобный консольный калькулятор для быстрого расчета баллов канала на Twitch. Помогает мгновенно узнать чистый выигрыш и общую выплату при ставках на стримах.



\## ✨ Особенности

\* Автоматически округляет результат до целого числа (как на самом Twitch).

\* Показывает общую сумму выплаты и чистую прибыль отдельно.

\* Не требует установки Python — работает как самостоятельное приложение.



\## 🚀 Инструкция по запуску

1\. Скачайте файл `twitch\_money.exe` из этого репозитория.

2\. Запустите его двойным щелчком мыши (в Windows).

3\. Введите количество баллов, укажите коэффициент ставки и нажмите \*\*Enter\*\*.



English

Twitch Points Calculator 🎮

A simple and convenient console calculator for quickly calculating channel points on Twitch. It helps you instantly see your net winnings and total payouts when betting on streams.

✨ Features

* Automatically rounds the result to the nearest whole number (just like on Twitch itself).

* Shows the total payout amount and net profit separately.

* Doesn't require Python installation—runs as a standalone application.

🚀 Launch Instructions

1. Download the twitch_money.exe file from this repository.

2. Double-click it (on Windows).

3. Enter the number of points, enter the bet odds, and press Enter.
