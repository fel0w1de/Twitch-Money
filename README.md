 Twitch Points Calculator 🎮



Простой и удобный консольный калькулятор для быстрого расчета баллов канала на Twitch. Помогает мгновенно узнать чистый выигрыш и общую выплату при ставках на стримах.



 ✨ Особенности

 Автоматически округляет результат до целого числа (как на самом Twitch).

 Показывает общую сумму выплаты и чистую прибыль отдельно.

 Не требует установки Python — работает как самостоятельное приложение.



 🚀 Инструкция по запуску

1. Скачайте файл `twitch\_money.exe` из этого репозитория.

2. Запустите его двойным щелчком мыши (в Windows).

3. Введите количество баллов, укажите коэффициент ставки и нажмите на любую кнопку.
