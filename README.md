							Twitch Money



Простой и удобный калькулятор для быстрого расчета баллов канала на Twitch. Помогает мгновенно узнать чистый выигрыш и общую выплату при ставках на стримах.



							Особенности

 Автоматически округляет результат до целого числа (как на самом Twitch).

 Показывает общую сумму выплаты и чистую прибыль отдельно.

 Не требует установки Python — работает как самостоятельное приложение.



						     Инструкция по запуску

1. Скачайте файл "Twitch Money.zip"  из последней версии в этом репозитории.

2. Запустите его двойным щелчком мыши.

3. Введите количество баллов, укажите коэффициент ставки.

4.Нажмите любую кнопку чтобы закрыть программу.
